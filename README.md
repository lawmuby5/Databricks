Ecommerce Data Engineering Project

Cloud Cost Optimization & Modern Data Platform Migration

📌 Overview

Led an end-to-end data engineering transformation project to eliminate over-reliance on AWS-native services and reduce operational complexity, downtime, and cloud expenditure.

The project consolidated fragmented data workflows into a unified, scalable, AI-assisted data platform using Databricks and Medallion Architecture.

🚨 The Problem

The company relied heavily on AWS tools:

Amazon Redshift

AWS Glue

S3

Lambda

Python scripts

Challenges:

Frequent downtime

High cloud storage costs (~£300,000 annually)

Knowledge gaps across teams

Fragmented pipelines limited to a few engineers

Complex outputs difficult for stakeholders to interpret

Heavy e-learning costs (£30,000) to upskill on multiple AWS tools

🎯 My Objective

Reduce cloud dependency and simplify architecture

Consolidate ingestion → transformation → output into one platform

Enable AI-assisted querying and validation

Improve stakeholder interpretability

Ensure auto-scalability and job orchestration

Deliver before deadline

🛠️ Solution Architecture

Migrated architecture to:

Databricks

Implemented Medallion Architecture (Bronze → Silver → Gold layers)

Used PySpark for ETL pipelines

Used SQL for validation & fact-checking

Leveraged Databricks Unity Catalog for governance

Implemented job orchestration with scheduled frequencies

Utilized Databricks AI Genie for AI-powered troubleshooting & query validation

🧱 Data Pipeline Design
Bronze Layer

Raw ingestion

Structured and semi-structured data storage

Silver Layer

Data cleaning & transformation

Reusable datasets

Schema enforcement

Gold Layer

Business-ready datasets

Stakeholder-focused analytics

Optimized for dashboards & reporting
